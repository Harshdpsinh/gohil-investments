# Prompt set

These are the working prompts for this repo. They describe the CRM that already exists. They are not a brief for a new app, and reading them must not cause a data migration.

| # | Prompt | Use it when |
| --- | --- | --- |
| 1 | [PRD.md](PRD.md) | You need to know what the office actually does |
| 2 | [DESIGN.md](DESIGN.md) | You are touching a screen |
| 3 | [ARCHITECTURE.md](ARCHITECTURE.md) | You are adding a module or an endpoint |
| 4 | [DATABASE.md](DATABASE.md) | You are reading or writing Firestore |
| 5 | [API.md](API.md) | You are changing `api/` |
| 6 | [../AGENTS.md](../AGENTS.md) | Every session, first |
| 7 | [../README.md](../README.md) | A human wants the short tour |
| 8 | [IMPLEMENTATION.md](IMPLEMENTATION.md) | You are about to write the code |
| 9 | [SETUP.md](SETUP.md) | The app will not start or a secret is missing |
| 10 | [FEATURE.md](FEATURE.md) | The user asked for one new behaviour |
| 11 | [SECURITY.md](SECURITY.md) | Auth, webhooks, uploads, roles |
| 12 | [MCP.md](MCP.md) | Someone asks to add an MCP server |
| 13 | [INTEGRATIONS.md](INTEGRATIONS.md) | Firebase, Cloudinary, BHASH, Meta, Gmail |
| 14 | [TESTING.md](TESTING.md) | You are adding or running tests |
| 15 | [DEBUGGING.md](DEBUGGING.md) | A screen, send, or upload is wrong |

Start at [../AGENTS.md](../AGENTS.md).
